# Security

Security maintenance targets the latest published RWKit release. The legacy rw-parser-ng package is being replaced by RWKit; use MIGRATION.md to update.

Report suspected vulnerabilities through [private vulnerability reporting](https://github.com/DepsCian/RWKit/security/advisories/new). Include the affected version, reproduction steps, impact, and a minimal sample when possible. Avoid public issues containing exploit details or private assets.

No response-time guarantee is offered. Ordinary bugs belong in the issue tracker.
